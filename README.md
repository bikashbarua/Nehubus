# Nehubus
One stop android application for students that helps track their buses and schedule their time wisely

A Real-time fleet tracking system built using Flutter and Firebase Realtime Database. Designed to stream live vehicle coordinates and visualize them on an interactive map.
FEATURES:

Real-time location updates

Firebase-based backend synchronization

Role-based authentication

Map visualization (OpenMaps / MapTiler)

MVC-based architecture

Simple structure:
Driver App → Firebase → Student App
